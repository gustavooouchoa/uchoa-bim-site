Dúvidas sobre automação BIM

O que é automação no BIM e o que é o Dynamo? +
Automação no BIM é usar rotinas e scripts para executar tarefas repetitivas no modelo automaticamente. O Dynamo é a ferramenta de programação visual do Revit que permite criar essas rotinas conectando blocos, e que eu combino com Python para a lógica mais avançada.
Para que serve a automação com Dynamo no Revit? +
Para acelerar tarefas que demorariam horas na mão: extração de quantitativos, padronização de nomenclaturas, atualização de parâmetros, organização de folhas e conferência de dados, com muito menos erro.
A automação BIM integra com Excel? +
Sim. O Dynamo lê e escreve planilhas Excel, algo que o Revit não faz nativamente. Dá para levar quantitativos e dados do modelo para o Excel e trazer informações de volta para o modelo.
